# Postman Terminal Demo

Starter repo for the **Postman CLI** module on [LiftOff](https://www.postman.com/liftoff/modules/postman-cli/).

It holds one file, `openapi.yaml`: a small Tasks API spec that is intentionally rough. During the module you'll run `postman init`, make the spec agent-ready, build a collection and an environment, mock the API and push everything to your own Postman workspace, all from the terminal.

## Get started

Fork this repo **without renaming it** (LiftOff looks for `postman-terminal-demo` on your account), keep it public, then clone it:

```bash
gh repo fork Postman-Devrel/postman-terminal-demo --clone --default-branch-only
cd postman-terminal-demo
```

Then follow the steps on LiftOff.
